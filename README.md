# Free AR Missense Variant Demo

This is a marker-based WebAR demo for the missense-variant pathogenicity project.
It uses AR.js and A-Frame through free CDN links and the built-in Hiro marker.

## Run locally

Camera access normally requires HTTPS or localhost. From this folder, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a desktop browser for a quick test. For phone
recording, publish the folder through free GitHub Pages, or use another HTTPS static host.

## Marker

Print or display the Hiro marker from the official AR.js marker documentation:
https://ar-js-org.github.io/AR.js-Docs/marker-based/

## What the scene represents

- DNA: the genetic context of a missense variant.
- Primate, mammalian, and vertebrate labels: conservation feature groups.
- Multi-Kernel SVM: the project model that combines information from separate kernels.
- Pathogenic output: an illustrative model result, not a clinical prediction.
